La vostra postaAruba — non si tocca

Una cosa sola da sapere, ed è importante: la vostra posta non si tocca. Seguendo queste istruzioni il dominio non viene modificato per niente — si cambia solo il file del sito. Le email continuano a funzionare esattamente come adesso.

Se qualcuno vi propone di «cambiare i server dei nomi» o di «spostare il dominio», fermatevi e chiamateci: è l'unica manovra che può spegnervi la posta, e qui non serve.

Passo per passo

  1. Aprite il pannello di ArubaCliccate qui: admin.aruba.it. Vi si apre una pagina che chiede email e password. Sono quelle che Aruba vi ha dato quando avete comprato lo spazio web — spesso sono in una vecchia email di Aruba, cercate «Aruba» nella vostra posta.
  2. Entrate nella parte dell'hostingUna volta dentro, cercate la sezione che parla di Hosting (non «Domini», non «Posta»). Se vi perdete, potete andarci diretti da qui: managehosting.aruba.it.
  3. Cercate la gestione dei fileDentro l'hosting cercate una voce che parla di File, Gestione file o FTP. È lo strumento che vi fa vedere i file del vostro sito, come una cartella sul computer.
  4. Aprite la cartella del sitoVedrete un elenco di cartelle. Quella giusta si chiama www — su alcuni spazi si chiama htdocs o public_html. Apritela: dentro ci sono i file del vostro sito attuale.
  5. Mettete da parte il sito vecchioSe dentro trovate un file che si chiama index.html o index.htm, rinominatelo in index-vecchio.html. Non cancellatelo: così se qualcosa non vi torna, rimettete il nome di prima e tutto torna com'era.
  6. Caricate il file nuovoCliccate su Carica (o Upload) e scegliete il file index.html che vi abbiamo mandato. Aspettate che finisca: è un file un po' pesante, ci mette qualche secondo.
  7. Guardate il risultatoAprite il vostro indirizzo dal telefono. Dovreste vedere il sito nuovo. Se vedete ancora quello vecchio, aspettate due minuti e ricaricate tenendo premuto il tasto di ricarica.

Aruba ha anche le sue guide con le fotografie delle schermate: https://guide.aruba.it/hosting-e-domini/
