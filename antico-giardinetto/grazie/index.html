La cosa più importante: non toccate niente della posta. Le vostre email funzionano grazie a certi codici del dominio che si chiamano record MX. Seguendo queste istruzioni non li sfiorate nemmeno, perché il dominio non va modificato per niente: si sostituisce solo il file del sito. Se qualcuno vi propone di «spostare i server dei nomi», fermatevi e chiamateci.

Cosa fare, passo per passo

Vi abbiamo mandato un file solo, si chiama index.html. Dentro c'è tutto: testi, fotografie e caratteri. Non serve caricare altro.

  1. Entrate su admin.aruba.it con le credenziali del vostro hosting
  2. Cliccate su Gestione Hosting, poi Gestione File (oppure collegatevi in FTP)
  3. Aprite la cartella www (a volte si chiama htdocs o public_html)
  4. Caricate il file index.html che vi abbiamo mandato
  5. Se dentro c'è già un index.html o un index.htm, rinominatelo prima in index-vecchio.html: così potete tornare indietro in qualsiasi momento

Appena caricato, aprite il vostro indirizzo dal telefono: dovreste vedere il sito nuovo. Se vedete ancora quello vecchio, aspettate qualche minuto e ricaricate la pagina.

Il pannello del vostro fornitore è qui: https://admin.aruba.it
